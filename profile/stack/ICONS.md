# Toolkit icons

Brand marks are from [Simple Icons](https://simpleicons.org/), pinned to
[commit `4d29a35c954699b389a834aacc97dd6e7e74143c`](https://github.com/simple-icons/simple-icons/tree/4d29a35c954699b389a834aacc97dd6e7e74143c).
The collection is distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/4d29a35c954699b389a834aacc97dd6e7e74143c/LICENSE.md).
Individual marks remain subject to their respective trademark guidelines.

The cards use the Python and Go brand marks from this collection. Category
pictograms are original SVG artwork. Technology chips use text labels, keeping
the inventory readable without suggesting unofficial brand marks. All symbols
are embedded in the rendered toolkit; displaying it requires no external requests.

Edit `toolkit.json` and run `python3 scripts/build-tech-stack.py` to regenerate
the desktop, narrow mobile, and wide mobile layouts and the README text fallback.
Language-specific tools belong to their language card. Shared infrastructure
and tooling appear once in separate cards. Python tools use the optional
`section` field for subgroups within the card.
