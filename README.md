## About me

**4+ years in backend engineering**, at **Doubletapp since 2023**. I design systems and shape product decisions with clients, balancing reliability, delivery speed, and business value.

**Tech Lead experience:** led **3 backend developers and 1 ML developer** on an AI-agent platform. I mentor engineers and conduct technical interviews.

I develop **Agent Skills, custom MCP (Model Context Protocol) tools, and agent workflows** for task decomposition, dependency planning, context gathering, and development automation.

I treat **engineering processes** as part of the product: I improve CI pipelines, code review, and development and task-management workflows to make collaboration clearer and delivery more reliable.

### Systems I work on

- **High-load backends** — APIs, async processing, caching, and production observability.
- **AI platforms** — agent orchestration, RAG pipelines, and knowledge bases.
- **Telegram / VK Mini Apps** — payments, integrations, and media processing.

My open-source work spans **AI and agent-development tools, MCP servers, and Agent Skills**, as well as **security, API governance, and automation** for backend projects. Open to collaboration — [let's talk](https://t.me/contact_vasiliev_dmitry).
